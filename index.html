上方快速選擇版型 → 左側製作規格、右側即時預覽 → 加入多版型組合 → 複製 HTML

① 選擇版型

預設 16px；規格標題及所有按鈕文字同步調整

EcLife 專用：模式 A 自動使用 &coid=；模式 B 自動使用 ?coid=。

Anker 商品代碼對照表（僅儲存在目前瀏覽器）

新品輸入代碼與完整網址後按「儲存對照」，日後可直接輸入代碼。此功能不會連線查詢官網，也不會自動同步其他同事。

② 製作規格

多版型快速組合

從下拉選單選擇 A～H 版型，會立即載入該版型的示範資料，右側同步顯示預覽。確認版型後，將範例商品編號與文字換成實際資料，再按「加入組合」。已加入區塊可直接編輯並自動更新。

提醒：下拉選單提供示範資料供預覽，正式上架前請替換商品編號及連結。

目前為單一版型；加入後可繼續選擇其他版型。

B｜色塊＋文字排列設定

使用固定欄數的傳統 HTML 表格，避免第三個規格意外落到下一排。每排 4 個、長文字或手機窄畫面仍可能擁擠，請以 EcLife 前台測試為準。

直式可選每排顏色數量；橫式每色一列，容量優先橫排，空間不足時自動換行，不縮小文字。

每種顏色可新增多個容量；每個容量需填入自己的商品編號與連結。

每一組都有自己的標題（例如「規格:1TB」），各組獨立換行；每個顏色按鈕可設定不同商品編號。

商品網址可選 Prod 或館別分類模式；追蹤碼可留空。範例編號為示意，正式上線前請替換成正確編號。

③ 即時預覽

E 分組版：沿用 EcLife 已成功存檔的簡易 a 標籤及行內樣式，加入分組標題與換行；請先在單筆商品測試。

⑤ 貼入舊 HTML，重新編輯

將以前產生的 HTML 語法貼到下方，再按「解析並載入」。成功後即可修改規格文字、顏色、容量、商品編號和連結。

⑥ 最終上架 HTML

上架 HTML 不含備份編碼；請另外複製「編輯備份」，日後貼回第 ⑤ 區即可完整恢復編輯資料。舊版 v21 / v22 語法也可嘗試匯入。

本工具為 EcLife 專用，可離線使用。混合版型上架前請確認前台呈現及商品連結。
